# Inspect capabilities

- Query the current runtime or console information tool when available. Inspect the active workspace, selected harness, permission mode, tool catalog, relevant skills, and connection status as needed for the question.
- Distinguish installed or discovered items from tools callable in this session, enabled services from live connections, and staged work from completed work. Identify stale, missing, or untested status rather than assuming availability.
- Use registry details or permitted workspace files for specific skill instructions. A skill is guidance, not a tool, a grant of permissions, or proof of execution.
- Answer from observed data, state meaningful limitations, and never reveal credentials or private configuration unnecessarily.
